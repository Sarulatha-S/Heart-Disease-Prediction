# Heart Disease Prediction

## Project Overview
This project uses Machine Learning classification algorithms to predict the presence of heart disease based on patient health information.

## Objective
To develop a classification model that identifies potential heart disease cases using relevant medical and clinical indicators.

## Dataset
- Patient health measurements
- Demographic and clinical features
- Heart disease target labels

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and understanding
2. Data cleaning
3. Exploratory Data Analysis
4. Data preprocessing
5. Feature encoding and scaling
6. Train-test splitting
7. Classification model development
8. Hyperparameter tuning
9. Model evaluation

## Machine Learning Algorithms
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
- Artificial Neural Network (ANN)

## Model Evaluation
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Model Selection
K-Nearest Neighbors (KNN) was selected based on the highest recorded cross-validation F1-score of 0.8542.
